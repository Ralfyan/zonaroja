# ZonaRoja · La NFL contada desde España

Web para aficionados a la NFL en España: horarios en hora peninsular, dónde verla legalmente, el partido de Madrid, los 32 equipos, un test para elegir equipo y una guía para novatos.

## Cómo está hecha
HTML, CSS y JavaScript sin nada que instalar. Se publica sola con GitHub Pages cada vez que se sube un cambio.

- `app.js`: **todos los datos que hay que actualizar** están arriba del todo (equipos, partidos, franjas horarias, glosario).
- `style.css`: colores y diseño.
- Cada página es un `.html` (index, horarios, donde-ver, madrid, equipos, test, novatos, comunidad).

## Cómo ver los cambios en tu ordenador
Abre `index.html` con doble clic.
